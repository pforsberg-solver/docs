## August 28, 2026 (Week 35)

### New Features and Enhancements

1. [Rollups](https://help.app.solverglobal.com/knowledge-base/rollups/) allow users to control the data that gets added to a dimension attribute, similar to Data Validation in Excel. Configured first in the Data Warehouse, similar to a dimension, rollups can be used in reporting for many practical financial and reporting purposes.
2. Audit Log Enhancements: This month’s update expands what is being tracked in the Audit Log. This includes:
   * Audit Log is now available to Customer Admins by default
   * Expanded audit actions to include many actions on the administration page. Details can be found [here](https://help.app.solverglobal.com/knowledge-base/audit-log/#audit-log-features).
   * Audit log will display the last 60 days of history.
     + Contact Solver Support if you need audit history older than 60 days.
     + Solver retains a rolling 365 days worth of audit logs.
   * Support export to .csv of the Audit Log.
3. Update user interface for [creating and maintaining Data Warehouse trees](https://help.app.solverglobal.com/knowledge-base/361-data-warehouse/#dimension-trees).
   * Replace the “click to drag” experience with a drag and drop experience.
   * Update action bar to align with the rest of the application.
     + Save is moved to the primary action bar.
     + Delete tree is move to the more actions button.
