title: "Hybrid Reporting"
---

<Expandable title="What is hybrid reporting?" defaultOpen>
  Hybrid Reporting, also referred to as Solver Cloud Agent, is a Solver feature enabling customers to connect Solver directly to supported ERPs. Using the feature enables users to run reports running live off their ERP system allowing for immediate reporting on financial numbers once they are posted/saved to the ERP. 
</Expandable>

<Expandable title="Supported ERPs">
  | ERP |
  | --- |
  | Acumatica 2016+ |
  | Dynamics GP 2016+ |
  | Dynamics SL 2016+ |
  | Dynamics AX 2009 |
  | SAP B1 V9+ |
  | Sage 100/300/500 2016+ |
</Expandable>
