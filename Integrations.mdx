## How integrations work

An integration loads data from a source system into the Data Warehouse. You create it from a connector in the **Integration Marketplace**, then run it manually or automatically as part of a job.

To open the list of integrations, go to **Data** > **Integrations**. The integrations table shows:

| Column | What it shows |
|---|---|
| **Name** | The name you gave the integration when you created it. |
| **Source** | The marketplace connector the integration uses. |
| **Status** | The current status, updated in real time (see [Integration statuses](#integration-statuses)). |
| **Last Run** | The date and time the integration last ran. |
| **Modified By** | The user who last changed the integration. |
| **Last Modified** | The date and time of that change. |

## Create an integration

1. Go to **Data** > **Integrations**.
2. In the upper-right corner, click **Add New**.
3. In the **Integration Marketplace**, select a Gateway, File Import, or ERP connector.

The integration creation wizard opens. For the remaining steps, see **How to build an integration** (TODO: link once the page exists).

## Run an integration

<Note>This section covers running an integration manually. To run integrations automatically, add them to a job.</Note>

1. Go to **Data** > **Integrations**.
2. Select the integration.
3. On the toolbar, click **Run**.

The status changes to **Queued**, then **Processing**, and finally **Success** or **Fail**.

### Cancel a running integration

While the status shows **Processing**, the **Run** button changes to **Cancel**. Click **Cancel** to stop the integration.

<Note>You can't cancel an integration that is running as part of a job.</Note>

## Edit an integration

1. Go to **Data** > **Integrations**.
2. Select the integration.
3. On the toolbar, click **Edit**.

The integration creation wizard opens at the **Task Manager** step, with the integration's current settings. For details on each step, see **How to build an integration** (TODO: link once the page exists).

## Delete an integration

1. Go to **Data** > **Integrations**.
2. Select the integration.
3. On the toolbar, click **Delete**.

## Button and action reference

### Integrations toolbar

| Button | What it does |
|---|---|
| **Add New** | Opens the **Integration Marketplace** to create an integration. |
| **Run** | Runs the selected integration. Changes to **Cancel** while the integration is processing. |
| **Edit** | Opens the selected integration in the creation wizard at the **Task Manager** step. |
| **Delete** | Deletes the selected integration after you confirm. |

### Integration statuses

| Status | Meaning |
|---|---|
| **Queued** | The integration is waiting to start. |
| **Processing** | The integration is running. |
| **Success** | The integration finished without errors. |
| **Fail** | The integration finished with errors. |
