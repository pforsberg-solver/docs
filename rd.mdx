## 1. Before You Begin

### Required license and permissions

To create templates, you need:

| Requirement | Purpose |
|---|---|
| **Standard** license | Required to create and design templates. |
| **Can manage Report and Input templates** permission | Lets you create, edit, and manage templates. |
| **Can run Report templates** permission | Lets you run templates to produce reports. |

> **Note:** Users who should only *run* templates, not edit them, need just the **Can run Report templates** permission.

### What you'll need

- Access to the Solver Cloud portal
- Microsoft Excel installed (template design happens in Excel through the Solver add-in)

---

## 2. How Report Building Works

A Solver report starts as a **template**: an Excel-based design that defines what data to pull and how to lay it out. When you run the template, Solver fills it with live data from your connected sources.

The overall workflow:

```
Create template (portal) → Design in Excel (Report Designer) → Run & test → Publish → Share
```

### Report templates vs. input templates

| Type | Use it for |
|---|---|
| **Report template** | Reading and presenting data (financial statements, analyses, dashboards). |
| **Input template** | Collecting and storing data, such as budgets and forecasts. Input templates support storage definitions. |

> **Note:** Report templates don't support the storage definitions that input templates need. If you've built a report template and later need data storage, download it and upload it again as an input template.

## 3. Step 1: Create a Template

You can start from a blank template or copy an existing one.

### Option A: Create a new blank template

1. Go to the **Report Templates** page (or **Input Templates** for an input form).
2. On the toolbar, click **New**, then select **Create New Template**.
3. In the **New report template** dialog box, type a name in the **Name** field.
   - The **Company** field shows the data source the template will use (for example, *Data Warehouse*).
4. Click **Create**.

The new template appears in the template list. You are automatically its **owner** and **author**.

**What the New menu options do**

| Option | What it does |
|---|---|
| **Create New Template** | Creates an empty template you design from scratch. |
| **Upload Template** | Adds an existing template file from your computer to the portal. |

> **Tip:** Templates are listed in alphanumeric order. To find one quickly, click **Recent** to filter the list or type in the search box. You can rename templates at any time.

### Option B: Copy an existing template

Copying is the fastest way to build a report that's similar to one you already have.

1. On the **Report Templates** page, select the template to copy.
2. On the toolbar, click **…** (more actions), then select **Duplicate**.
3. In the **Duplicate report template** dialog box, type a name for the copy.
4. Click **Duplicate**.
5. With the new copy selected, click **Edit in Report Designer**.

> **Important — use Duplicate, not Excel's Save As.** Saving a template under a new name in Excel creates a new file, but that file stays linked to the *original* template in the portal. The portal always opens the most recent version, so your "copy" effectively overwrites the original's history. If you need to keep a separate earlier version you saved with Save As, upload it to the portal under a unique name.

---

## 4. Step 2: Open the Template in Report Designer

1. In the template list, select your template.
2. On the toolbar, click **Edit in Report Designer**.

Excel opens with the Solver design tools loaded.

> **Tip:** If Excel doesn't open on its own, open Excel manually, select your template in the portal, and click **Edit in Report Designer** again.

### Viewing template details in the portal

| Control | Location | What it does |
|---|---|---|
| **Information** | Upper right of the list | Opens a pane with the template's **Activity** (history and comments) and **Details**. |
| **List view / Card view** toggle | Upper right of the list | Switches between a table of templates and visual cards. |
| Draft icon | Next to the template name | Indicates the template has unpublished changes. |

## 5. Step 3: Understand the Design Workspace

When you edit a template, Excel shows three main tools:

| Component | Purpose |
|---|---|
| **Report Designer pane** | Browse your data and drag fields into the report. |
| **Solver Reporting ribbon** | Access commands for creating, configuring, and designing reports. |
| **Layout Editor** | Configure how rows, columns, and filters behave. |

> **Important:** Row 1 and column A are reserved for advanced template functions. Leave them empty and start your design in cell B2 or later.

### 5.1 The Report Designer pane

The pane on the left side of Excel is where you find the data to put in your report.

**Connection information (top of pane)**

- **User name** — the account you're signed in with.
- **Data connection** — the source the template pulls from (for example, *Data Warehouse*). This name is a link: click it to switch to a different data source. You can also change it from the ribbon using **Data Connection** in the **Configuration** group.

**Design and Run tabs**

| Tab | Mode | What it's for |
|---|---|---|
| **Design** | Design mode | Browse data and build the report. Save your work here. |
| **Run** | Run mode | Choose parameter values and run the report to see results. |

**Search box** — Type a term to find fields within the active module.

**Module bar (bottom of pane)** — Lists the available modules, such as *General Ledger* and *Accounts Receivable*. Click a module to make it active and see its contents.

- Drag the **ellipsis handle** (`.........`) up or down to resize the module area. When the area is enlarged, some modules or options may be hidden from view.
- Click the **Configure** button (`»`) to show more or fewer buttons and to access additional sections, including **Period Functions**, **Trees**, **Expressions**, **KPIs**, **Drill-To Definitions**, and **Report Parameters**.

> **Note:** Available modules depend on your organization's data sources, such as your data warehouse, ADP, Salesforce, or Microsoft CRM. Contact your partner, sales manager, or project manager for the full list of connectors available to you.

### 5.2 Understanding the data building blocks

Each module contains fields of different types. Knowing them helps you choose the right field for each part of your report.

| Building block | What it is | Example | Typical use in a report |
|---|---|---|---|
| **Module** | A customizable group of dimensions, also called a fact table. It records business events along with the dimensions that describe them. | General Ledger | Choose the subject area of your report. |
| **Dimension** | Describes the people, things, or categories involved in the business. Dimensions are shared across modules. | Account, Department, Entity, Period | Rows, columns, and filters. |
| **Attribute** | Extra information about a module or dimension. | Account Description, Account Type | Labels and descriptive columns. |
| **Measure** | A numeric field defined in the module. | Annual Amount, Monthly Amount | The values your report calculates and displays. |

> **Tip:** Hover over a module and click **>** to expand it and see its dimensions and attributes. Expand a dimension the same way to see its attributes.

Your organization's dimensions may differ from the examples shown here, but a General Ledger module typically includes Account, Department, Entity, and Period.

### 5.3 Period Functions

**Period Functions** are prebuilt time ranges, such as *12 Months Rolling*, *All Year 2 Years Ago*, or *First Period This Year*. They're usually combined with a period parameter, so the person running the report picks a period and the function calculates the range relative to it.

**To find Period Functions:** click the **Configure** button (`»`) at the bottom of the Report Designer pane, then select **Period Functions**.

### 5.4 The Solver Reporting ribbon

The **Solver Reporting** tab in Excel's ribbon is organized into groups:

| Group | Buttons | Purpose |
|---|---|---|
| **Create Report** | New Blank, New Current, Upload Report | Start or upload report designs. |
| **Configuration** | Data Connection, Report Properties | Set the data source and template settings. |
| **View** | Report Designer, Layout Editor, Report Parameters | Show or hide the design panes. |
| **Design** | Auto Parameters, Layout Comments, Options | Control design behavior. |
| **Help** | Help | Open Solver help. |

By default, both **Report Designer** and **Layout Editor** are turned on. Click a button in the **View** group to show or hide its pane.

> **Note:** Detailed instructions for individual ribbon commands are covered in later lessons.

## 6. Step 4: Build the Report Layout

### 6.1 Add fields to the worksheet

Drag fields from the Report Designer pane into Excel cells. The Layout Editor displays the message *"Start by dragging fields from the Designer into Excel"* until you add your first field.

### 6.2 Configure the layout in the Layout Editor

The Layout Editor controls how each part of the report behaves. Use it to configure:

- **Row groups and column groups** — which dimension members repeat down rows or across columns.
- **Cell-based measures** — values calculated in individual cells.
- **Filters** — which data is included.
- **Grouping and sorting** — how results are organized.
- **Period aggregation** — how values roll up over time.
- **Sheet filters** — filters that apply to the entire active worksheet.

Row, column, and sheet filters can either be linked to **parameters** (chosen when the report runs) or **hard-coded** to specific values.

**Layout Editor links**

| Link | What it does | Who sees it |
|---|---|---|
| **Create new group** | Manually creates a selection group (advanced). | All designers |
| **Create storage** | Manually creates a storage mapping for saving data (advanced). | Users with Planning permissions only |

> **Note:** Storage is used for budget and input templates. For more, see the *Planning Essentials* course.

> **Note for upgraded templates:** Templates converted from version 4.x may include period aggregation definitions. In version 5.0, these are defined as filters combined with the period parameter.

### 6.3 Add sheet filters

Sheet filters limit the data for the whole report, for example to a single period or entity.

1. In the Layout Editor, click the **sheet filter** button at the upper left.
2. Drag a dimension (such as **Period**) from the Report Designer pane into the **Sheet Filters** area.

### 6.4 Control parameters with Auto Parameters

**Auto Parameters** (in the ribbon's **Design** group) is on by default. When it's on, any dimension you drag into a row, column, or sheet filter automatically becomes a **report parameter**, a value users select at run time.

For example, if you add **Period** as a sheet filter with Auto Parameters on:

- The filter value shows as `@Period`.
- **Period** is added to the **Report Parameters** pane.

> **How to read the @ symbol:** When `@` appears before a dimension name, that dimension is a parameter. It may still be hidden from users.

**When to turn Auto Parameters off:** A filter doesn't have to be a parameter. If you want to lock a filter to specific values (for example, always show Entity 100), click **Auto Parameters** to turn it off *before* dragging the field into the filter.

### 6.5 Manage report parameters

Open the **Report Parameters** pane from the ribbon's **View** group. Drag fields into the pane to create parameters. Use the arrow buttons to reorder them, the edit button to change one, and the **X** button to remove one.

---

## 7. Step 5: Run the Report

1. In the Report Designer pane, click the **Run** tab.
2. For each parameter shown (for example, **Choose Period**), enter a value or click the search button to pick one.
3. Click **Run**.

Solver fills the template with data based on your selections.

> **Tip:** You can't save changes while in run mode. To save formatting or design updates, switch back to the **Design** tab first.

## 8. Step 6: Publish, Share, and Manage the Template

### 8.1 Publish your draft

New templates, and any changes you make, stay in **draft mode** until you publish them. A draft icon appears next to the template name.

| Action | What it does |
|---|---|
| **Publish Draft** | Makes your current changes the official version of the template. |
| **Discard Draft** | Removes all unpublished changes. If the template has never been published, it goes back to a blank design. |

> **Important:** Publish your template when it's ready. Unpublished changes aren't part of the official version.

### 8.2 Who can see your template

When you first create a template, only you can see it. It appears on the **Report Templates** or **Input Templates** page in your tenant.

### 8.3 Share templates with others

To share a template with other Standard users, add it to a **shared category** using **Add to Category** on the toolbar.

Check each user's permissions based on what they should be able to do:

| The user should be able to… | Required permissions |
|---|---|
| Edit and run the template | **Can manage Report and Input templates** + **Can run Report templates** |
| Run the template only | **Can run Report templates** |

For details, see *Sharing Templates and Reports*.

### 8.4 Transfer ownership

To hand a published template to another user:

1. Select the template.
2. Click **…** (more actions), then select **Change Ownership**.
3. Choose the new owner and save.

The template disappears from your list right away. If the new owner is already signed in, they need to refresh their browser to see it. For details, see *Setting Up and Maintaining Users and Roles*.

> **Note:** **Change Ownership** is available only for published templates.

## 10. Best Practices

- **Duplicate instead of Save As.** Use **…** > **Duplicate** to create a copy. Excel's Save As keeps the new file linked to the original template.
- **Keep row 1 and column A empty.** They're reserved for advanced template functions.
- **Decide on parameters before you drag.** Turn **Auto Parameters** off before adding a filter you want fixed to specific values.
- **Save in Design mode.** Changes made in run mode can't be saved.
- **Publish when you're done.** Drafts aren't the official version, and unpublished templates can't change ownership.
- **Use clear, sortable names.** Templates sort alphanumerically, so a consistent naming pattern makes them easier to find.
- **Review permissions before sharing.** Give edit permissions only to users who need to change the template.

## 11. Troubleshooting

| Problem | Solution |
|---|---|
| Excel doesn't open after clicking **Edit in Report Designer**. | Open Excel manually, select the template in the portal, and click **Edit in Report Designer** again. |
| My changes didn't save. | You may be in run mode. Switch to the **Design** tab and save. |
| A filter became a parameter when I wanted a fixed value. | Turn off **Auto Parameters**, remove the filter, and drag the field in again. |
| I don't see **Create storage** in the Layout Editor. | This option requires Planning permissions. |
| I used Save As, and the portal opens the wrong version. | The portal opens the most recent version linked to the original. Upload the earlier file under a unique name to keep it separately. |
| **Change Ownership** is unavailable. | Publish the template first. |
| The new owner can't see a transferred template. | Ask them to refresh their browser. |
| A module or option is missing from the pane. | Drag the ellipsis handle to resize the area, or click **Configure** (`»`) to show more buttons. |
| I need to add data storage to a report template. | Download it and upload it as an input template. |

## 12. Glossary

| Term | Definition |
|---|---|
| **Attribute** | Additional descriptive information about a module or dimension. |
| **Auto Parameters** | A setting that automatically turns filtered dimensions into report parameters. |
| **Design mode** | The Report Designer state for building and saving a template (Design tab). |
| **Dimension** | A category describing business objects, such as Account or Department. Shared across modules. |
| **Draft** | A template with unpublished changes. |
| **Input template** | A template used to collect and store data, such as budgets. |
| **Layout Editor** | The pane for configuring row groups, column groups, filters, sorting, and aggregation. |
| **Measure** | A numeric field within a module. |
| **Module** | A fact table containing business events and the dimensions that describe them. |
| **Parameter** | A value the user selects when running a report. Shown with an `@` prefix, such as `@Period`. |
| **Period Function** | A prebuilt time range, such as a 12-month rolling period, used with a period parameter. |
| **Report template** | A template used to retrieve and present data. |
| **Run mode** | The Report Designer state for running a report (Run tab). Changes can't be saved here. |
| **Sheet filter** | A filter applied to the entire active worksheet. |
| **Shared category** | A category used to share templates among Standard users. |
