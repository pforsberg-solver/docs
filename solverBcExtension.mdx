## Overview

Solver develops an extension available for download within your Business Central tenant that provides a well-formatted API to be used within the Solver application for both QuickStart and non-quickstart implementations.

* The extension is required for all QuickStart implementations.
* Solver strongly recommends installing this extension for all implementations between Solver and Business Central.

## Installing the Extension

As a Business Central admin

1. Log into Business Central.
2. Search for Extension Marketplace to open Microsoft App Source.
3. Search for Solver.
4. Click **Get It Now** on the Solver extension.![](/wp-content/uploads/2022/10/Snag_6fc6a3a.png)

The installation of this connector should take a couple of seconds. Once installed you can begin using the Solver BCv2 Connector.

* This extension is installed on all Companies that are part of the currently logged-in Environment. Each Company must be active (not expired) to successfully install the extension. Users will need to delete any expired companies to install the extension.

## Upgrading the Extension

From time to time, Solver will release updates to the Extension. Release notes can be found at the bottom of this article. To update an extension, as a BC Admin,

1. Search for Extension Management.  
   ![](/wp-content/uploads/2022/10/Snag_6ff6922.png)
2. The screen will list installed extensions. Search for “Solver” and select the Solver extension. Choose Uninstall.![](/wp-content/uploads/2022/10/Snag_6ff2582.png)
3. In the popup, choose Delete Existing Data and click Uninstall. A prompt will notify you that all data will be delete related to the Solver Extension, click Yes.![](/wp-content/uploads/2022/10/Snag_6ff1a18.png)
4. Upon clicking Uninstall, you will be warned again about deleting data, click Yes.![](/wp-content/uploads/2022/10/Snag_6ff3020.png)
5. The process will take about 10-30 seconds and the extension will be uninstalled.

Redownload the extension via the instructions listed above and you have successfully upgraded your extension.
